# CepalStat_ML_Interlock

## 📊 Predictive Social Risk Intelligence  
**Machine Learning model based on CEPAL data**

## 📌 Project Overview

**CepalStat_ML_Interlock** is a data-driven solution developed during a hackathon to help institutions move from descriptive analytics to **predictive decision-making** in the context of sustainable development.

This Machine Learning model automates the detection of **social risk patterns linked to inequality**, enabling policymakers to combine predictive insights with poverty and mortality data to prioritize interventions and monitor countries facing persistent social challenges.

The project was inspired by a global challenge:

- More than **231 Sustainable Development Goal (SDG) indicators** are currently monitored worldwide.  
- However, only **17% of SDG targets are on track** to be achieved.  

This reveals a critical issue: having more data does not always lead to better decisions.

---

## 🚨 Problem Statement

Organizations such as the **United Nations Development Programme (UNDP)** need to identify which territories are falling behind **before** social gaps deepen.

Traditional analytical models often:

- Describe past conditions instead of future risk  
- Miss nonlinear interactions between indicators  
- Delay strategic interventions  
- Lead to reactive resource allocation  

What decision-makers need is not more information — they need **predictive intelligence**.

---

## 💡 Proposed Solution

We developed an interactive dashboard powered by Machine Learning that integrates three high-impact indicators:

- Poverty Rate  
- Gini Index (Inequality)  
- Infant Mortality Rate  

These variables were selected because they represent complementary dimensions of development:

- **Magnitude of need**  
- **Structural inequality**  
- **Critical social outcomes**

Unlike traditional methods, the model detects **nonlinear relationships**, such as cases where the Gini Index may increase risk at both low and high levels.

---

## 🤖 Machine Learning Approach

The solution uses predictive models such as:

- Random Forest  
- Supervised learning pipelines  
- Feature importance analysis  
- Risk classification logic  

This enables more robust forecasts of where vulnerability may intensify.
